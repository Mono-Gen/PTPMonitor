# バイナリファイルの管理除外計画

Gitリポジトリ内に含まれているビルド済みバイナリ（.zip）を、プロジェクト規定（`global_rules.md`）に従って管理対象から除外します。

## 修正内容
1.  **追跡対象からの削除**:
    - `git rm --cached PTPMonitor_v1.6.7.zip` を実行し、Gitのインデックスから削除する（ローカルファイルは保持）。
2.  **コミット**:
    - 削除を確定させるためにコミットを行う。

## 検証計画
- `git ls-files` を実行し、`.zip` ファイルが表示されないことを確認する。
