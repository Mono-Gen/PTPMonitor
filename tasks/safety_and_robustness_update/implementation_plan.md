# 安全性および堅牢性向上のための修正計画

プロジェクトのルール（`ui_ux_rules.md`, `resource_management_rules.md`）に基づき、操作ミス防止と通信の安定性を強化します。

## 修正内容
1.  **Web UI の改善 (安全性とフィードバック)**:
    - 危険操作（全データ消去、オフライン消去）に `confirm()` ダイアログを追加。
    - 画面右上に「最終更新時刻」を表示するエリアを追加。
    - CSSに「Liveインジケーター（点滅）」を追加。
2.  **ネットワーク通信の強化**:
    - `Socket.Bind` の対象を `IPAddress.Any` から選択された `currentLocalIp` に変更。
    - `Socket.ReceiveTimeout` に 1000ms（1秒）を設定し、ハングアップを防止。

## 検証計画
- `PTPMonitor.cs` が正常にコンパイル可能であることを確認。
- Web UI のボタンクリック時に確認ダイアログが表示されることをコードレベルで確認。
- 通信ロジックに破壊的な変更がないことを再確認。
